# Report It Easy

Build a mobile-first, beginner-friendly web app called "Report It" that helps people easily report civic hazards like potholes or broken sidewalks.

The home page should be clean and inviting, featuring a massive "Snap a Photo" button. Once a photo is uploaded, show a brief, engaging loading animation (e.g., "Analyzing issue..."). Finally, display a clean results page showing the uploaded photo alongside an automatically generated, official-looking report that includes the issue category, simulated GPS coordinates, and a professional text description of the hazard. Include a big "Submit to City" button at the bottom. Make the UI modern, bright, and highly polished.
